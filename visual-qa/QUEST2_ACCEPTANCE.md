# Physical Meta Quest 2 acceptance — prepared, NOT executed

**Scope:** Phase 4 catalog and Phase 5 combined regression on a physical Quest 2. A green desktop IWER run is necessary but insufficient for hardware acceptance.

**Before entering VR:** Record date, exact git commit/build SHA, Quest 2 software version, browser, controller firmware if known, headset boundary, eye-spacing setting, user standing/seated posture, tracking conditions and operator. Verify local build is served through a valid secure context reachable to the headset; do not silently use a different build.

**In-headset functional checks:**
1. Enter and re-enter VR; large tutorial stays closed, `?` remains reachable by either controller's trigger ray, Close works, and grip never opens help.
2. Identify all five distinct tray tools from the start without excessive head rotation; ensure normal hand reach and no controller/scene occlusion in *both* eyes.
3. Grip mirror with left hand and composite with right; observe tip clearance, natural shaft orientation, pose-following under translation/rotation, release/return, and no double ownership.
4. Open TOOLS catalog via either controller and read each name and purpose at natural headset viewing distance. Confirm selection highlight, no clipping/overlap of purpose with RETURN/RESET/CLOSE, and that the lower panel does not conceal tray instruments.
5. Select another instrument and verify selected entry/purpose; RETURN does not clone or steal a held tool. RESET returns all tools. Close catalog and verify no phantom ray targets.
6. Disconnect/reconnect a controller or lose tracking safely: held tool returns to tray, no stale controller mesh or ownership. Check left/right handedness.
7. Repeat after XR session exit and reentry, verifying initial tray positions and closed panels.

**Evidence:** Save real left/right headset screenshots or short headset recording, annotate screenshot eye/camera limitations, log all individual pass/fail outcomes, and note discomfort or readability issues. Record observed FPS and tracking qualitatively separately from functional outcomes. No source/desktop mock screenshot may be labelled physical Quest 2 evidence.

**Decision:** Accept only after a human operator checks both functional and visual ergonomics on the real headset. Record unresolved issues and explicit sign-off; no hardware acceptance has yet been performed.
