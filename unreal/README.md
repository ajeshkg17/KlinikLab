# Unreal Engine 5.9 project

The complete source project is in [`KlinikLabUnreal59/`](KlinikLabUnreal59/). Open `KlinikLabUnreal59/KlinikLabUnreal59.uproject` with Unreal Engine 5.9.0.

The snapshot includes project configuration, Unreal assets and maps, curriculum sidecar data, source assets, scripts, and the project README. Generated caches, local editor state, Saved output, and Gemini client settings are excluded.

Unreal `.uasset` and `.umap` files are included for project completeness; GitHub text review tools may not be able to inspect their binary contents. Source scripts and documentation are directly reviewable.
